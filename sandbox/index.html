POMDP Demo for Breast Cancer Follow-up

This is an interactive demo of a partially observable Markov decision process (POMDP) for breast cancer follow-up. At each simulated visit, the model updates its belief about the patient's hidden recurrence status from an imperfect observation, then recommends how intensive the next visit should be.
